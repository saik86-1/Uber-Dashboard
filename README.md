# 🚖 Uber Trip Analysis — Power BI Dashboard

A complete end-to-end analytics project built in **Power BI** to explore booking behavior, trip patterns, peak timings, vehicle performance, and location trends using Uber trip data.  
This dashboard provides actionable insights through clean visuals, interactive slicers, and multiple analysis pages.

## 📊 Dashboard Pages

### **1. Overview Analysis**
High-level KPIs and summary insights:
- Total Bookings, Total Booking Value, Avg. Booking Value  
- Total Trip Distance & Avg. Trip Time  
- Payment Type Split  
- Day/Night Trip Distribution  
- Daily Booking Trend  
- Vehicle-wise performance (UberX, Comfort, Black, XL, Green)  
- Most Frequent Pickup/Dropoff Points  
- Farthest Trip and Location-based comparisons  

---

### **2. Timeline Analysis**
Understanding booking behavior over time:
- Bookings by Pickup Hour (area chart)  
- Bookings by Day of Week  
- Heatmap of Bookings by Day & Hour  
- Total Bookings, Value, and Distance across time  

---

### **3. Detailed Trip View**
A complete, scrollable table of:
- Trip ID  
- Pickup Date & Time  
- Vehicle Type  
- Payment Method  
- Trip Distance  
- Booking Value  
- Location  
Includes totals at the bottom for validation and quick audit checks.

---

## 🛠️ Key Features

- 📍 **Interactive slicers**: City and Date filters  
- ♻️ **Dynamic DAX measures** for totals, averages, and time-based comparisons  
- 🎨 **Clean UI** with minimalist grayscale theme  
- 🚘 **Vehicle-level drilldowns** for operational insights  
- ⏱️ **Peak time identification** using combined time and weekday patterns  

---

## 📁 Tech Stack

- **Power BI Desktop**  
- **Power Query** (Data Cleaning & Transformation)  
- **DAX** (Custom Measures & Calculated Columns)  

---

## 📦 Dataset

Includes trip-level details such as:
- Pickup Date & Time  
- Vehicle Type  
- Payment Type  
- Trip Distance  
- Booking Value  
- Location Info  

(Data anonymized for training/analysis purposes)

## 🚀 How to Use

1. Download the `.pbix` file from this repository  
2. Open in **Power BI Desktop**  
3. Use the slicers to explore insights interactively
